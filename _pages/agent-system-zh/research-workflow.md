<a id="begin-with-a-mathematical-obligation"></a>

## 从数学开始待解决事项

一个有用的研究系统必须在探索回答问题的方法的同时保留问题。考虑这个重复任务：证明使用射影定理，但目标是紧致 Kähler。任务是确定该步骤是否继续存在，找到适用的替换，或隔离丢失的引理。仅仅用分析语言重写论证并不是进步。

冻结原来的目标。记录类别、维度、奇点、系数场、正性假设以及断言是绝对的还是相对的。维护一个单独的提议的附加假设列表。更强假设下的证明是部分结果，而不是原始任务的完成。

<a id="the-shared-artifact"></a>

## 共享研究记录

每个任务都带有命题版本、可用前提、一个请求的结论、一个证据包、未解决的待解决事项和一个停止条件。每个派生的断言都命名了其前提的确切版本。文献记录包括定理编号、来源版本、精确假设以及建议将对象替换为定理。

| 模式 | 具体研究行动 | 所需的输出和故障测试 |
|---|---|---|
| 链接 | 提取定理，对齐假设，测试其应用 | 当无法提供假设时停止 |
| 路由 | 单独的来源查找、符号计算和证明审查 |未解决的路线；不要猜测工具的能力 |
| 并行工作 | 搜索替换定理并构建阻碍示例 | 合并证据，而不是投票；保留分歧 |
| 规划 | 将所需的蕴涵分解为引理 | 公开所有假设并检测循环依赖关系|
| 检索 | 定位引用背后的确切定理 | 相关摘要不是适用的定理 |
| 表示更改| 传递到模型、divisor、光纤或形式化命题 | 提供前向构造和返回蕴涵 |
| 反射| 挑战最弱的推理 | 返回局部缺陷或合理的固定 |
| memory | 保存可重用结果及其范围 | 检索必须保留资格和失效状态 |
| 恢复 | 工具故障或拒绝引理后恢复 | 区分基础设施故障和数学故障 |
|终止 | 关闭有界尝试 | 单独报告已证明、有条件、反驳或未解决 |

<a id="execute-one-attempt"></a>

## 执行一次尝试

首先检索来源并重建其假设。接下来构建一个将这些假设与当前对象相匹配的表。对于每个不匹配的行，打开待证事项。选择一个有界动作：找到替换结果，证明该假设，或测试候选障碍。即使尝试失败，也要保存结果证据。

反例必须满足每个原始假设并违反结论。数值测试可以提出一个建议，但四舍五入和抽样不能建立一个普遍的断言。精确计算仅证明该计算编码的命题；将其与几何问题连接起来的是一个单独的待解决事项。

审查论证针对冻结目标。一个成功的局部引理应该以其精确的范围来存储。如果没有路由关闭，则返回最小的未解析蕴涵以及排除尝试路由的证据。不要将此称为解决方案。

<a id="evaluation-before-scaling"></a>

## E缩放前的评估

根据已知的论证和故意损坏的变体的问题构建一个小型基准。包括缺失的射影性假设、不合理的下降、循环引理以及带有已删除限定符的来源引用。将评估案例与用于调整系统的提示分开。

衡量正确的诊断、错误接受、引用的再现性、获得有用的部分结果的时间以及每个独立的已审查待解决事项的成本。与使用相同工具和预算的智能体进行比较。只有当多重角色能够改善这些结果时，多重角色才是合理的。新颖的研究没有已知答案的基准：保留论证并安排外部数学审查，而不是报告自动成功分数。

<a id="reading-the-diagrams"></a>

## 读图

一个有用的图表回答了一个特定的问题：研究记录移动了什么，做出了什么决定，失败时会发生什么，或者哪些前提共同暗示了一个结论？区分执行箭头和逻辑蕴涵。搜索循环为正规；不支持的证明依赖关系的循环则不是。标有“原因”、“学习”和“验证”的装饰框未指定这些接口约定。

<a id="sources-and-scope"></a>

## 来源和范围

一般工作流程词汇遵循 Gulli，*Agentic Design Patterns*，第 1-7 章（已检查本地附件的内容）。 [Anthropic 的工程帐户](https://www.anthropic.com/research/building-effective-agents) 将预定义工作流程与智能体定向执行区分开来，并鼓励从更简单的组合开始。上述数学协议和评估案例是设计建议，而不是这些系统解决开放问题的经验断言。 [验证页面](/posts/2026/08/agent-system-zh/verification-gate/)解释了模型审查和形式化检查的限制。

<a id="capstone-practice"></a>

## 顶点实践

完成一个关于已知定理应用的有界研究片段，并故意删除假设。导出原始目标、来源命题、假设表、拒绝的路线和最终结果。搜索预算停止问题必须仍未得到解决。

使用 [lab](/posts/2026/08/agent-system-zh/hands-on-lab/) 进行记录机制。单独提供数学证据。
